# Image credits

The demo products link product images from the manufacturers' and retailers' own image servers (change `product-images`, design D1). The images are not stored in this repository; the browser loads them from those servers, so the demo needs internet access, and a link the owner moves or removes falls back to the category placeholder. All rights in these images remain with their owners; they are used only to illustrate this non-commercial university demo. Phone images come from GSMArena's product pictures. Where the source has no image of the exact model, the closest model is used and named.
