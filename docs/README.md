# Documentation

This directory contains the documentation and design artifacts for the VoltStore project.

---

## Structure

```text
docs/
└── design/
    └── user-stories/
        ├── customer/
        │   ├── customer-user-stories.md
        │   └── customer-technical-insights.md
        ├── catalog-manager/
        │   ├── catalog-manager-user-stories.md
        │   └── catalog-manager-technical-insights.md
        └── inventory-worker/
            ├── inventory-worker-user-stories.md
            └── inventory-worker-technical-insights.md
```

- **[`customer/`](design/user-stories/customer/)**: User stories and technical insights for the Customer actor.
- **[`catalog-manager/`](design/user-stories/catalog-manager/)**: User stories and technical insights for the Catalog Manager actor.
- **[`inventory-worker/`](design/user-stories/inventory-worker/)**: User stories and technical insights for the Inventory Worker actor.
